# SARING PESAN
SISTEM DETEKSI PESAN PENIPUAN TELEGRAM BERBAHASA INDONESIA BERBASIS AI

Sebuah website klasifikasi pesan penipuan berbasis Artificial Intelligence. Website ini mendeteksi pesan berbahasa Indonesia yang didapatkan oleh pengguna di Telegram untuk mengatasi maraknya kasus penipuan online. Sistem menggunakan perpaduan pendekatan Naive Bayes dan Rule-Based dalam mengolah struktur pesan yang dianggap mencurigakan bagi pengguna. Dengan menggunakan pendekatan tersebut, AI juga turut berkolaborasi dalam menganalisis struktur pesan, mendeteksi modus manipulasi psikologis, menghitung tingkat risiko secara real-time, serta memberikan perlindungan aktif di Telegram.
